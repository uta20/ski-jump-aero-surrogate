# Ski Jump Aero Surrogate

スキージャンプの飛行を, 揚力・抗力を考慮した2次元質点モデルでシミュレーションし, **物理モデルの理解 → データ生成 → 機械学習(サロゲートモデル・感度分析)** までを一貫して行うプロジェクトです. 卒業研究(富岳を用いた空力CFD)で得た空力値(有効揚力面積・有効抗力面積)を, 軌道計算と飛距離の分析に接続することを目指しています.

| | |
|---|---|
| **現在の状態** | v0.1 — 物理コア(運動方程式・着地判定・テスト)を実装. **空力値(有効面積)は動作確認用のプレースホルダ** |
| **次のマイルストーン** | v0.2 — CFD結果(定常ケース)を有効面積として取り込む. 非定常CFD(3ケース)は実行待ち |

> **重要**: 現時点のデモで使っている質量・有効揚力面積・有効抗力面積・踏切条件は, すべて動作確認用の代表値です. 実在の選手・用具・CFD結果の値ではなく, 得られる飛距離も実際の競技を再現するものではありません.

---

## 目的とストーリー

1. **物理モデルの理解**: 運動方程式を自分で立て, 解析解(真空中の放物運動, 終端速度など)と突き合わせて実装の正しさを確認する
2. **データ生成**: 踏切速度・踏切角・風・有効面積などを変えながら, 疑似データセットを自作する
3. **機械学習**: 条件 → 飛距離の関係をサロゲートモデルで近似し, 感度分析で「何が飛距離を支配するか」を調べる

### 機械学習の位置づけ(誤解を避けるために)

質点モデルのODEはミリ秒で解けるため, **サロゲートによる計算の高速化そのものは主張しません**. 価値を置くのは次の3点です.

- **感度分析**: シミュレータに対するSobol指数を「正解の感度構造」とし, サロゲート上のSHAPなどがそれを再現できているかを検証する
- **不確実性の伝播**: 空力値の不確かさ(補間誤差, CFDの誤差, 文献値のばらつき)が飛距離のばらつきにどれだけ効くかを定量化する
- **ケース数が限られるCFDの活用**: 少数のCFDケースから, 軌道・飛距離への影響まで一貫して追えるようにする

合成データ上のMAEは, シミュレータに入れたノイズの大きさでほぼ決まるため, 実データを使った論文のMAEとの優劣比較には使いません. 論文の値は, パラメータ範囲やノイズ量を決める際の参考値としてのみ使います.

## 物理モデル

選手+用具を質量 *m* の質点とみなし, 空気に対する相対速度を `v_rel = v − w`(*w* は風速ベクトル)とします.

```
m dv/dt = m g
          − (1/2) ρ A_D |v_rel| v_rel                   (抗力: v_rel と逆向き)
          + (1/2) ρ A_L |v_rel| (−v_rel_y, v_rel_x)     (揚力: v_rel に垂直で上向き側)
```

- **A_D = Cd·S は有効抗力面積, A_L = Cl·S は有効揚力面積** [m²] です. 空力値はこの2つを直接扱い, 基準面積 S の定義は別に持ちません. CFDで得た力を (1/2)ρv² で割れば, そのまま有効面積になります

- 座標系: 原点は踏切点, x は前方が正, y は鉛直上向きが正
- 風は水平成分のみ. +x 向き(追い風)が正, 向かい風は負
- 着地は「位置が斜面の高さを上から下へ横切る瞬間」として, `scipy.integrate.solve_ivp` のイベント検出で求める
- 飛距離は, 踏切点から着地点まで**斜面に沿って測った長さ**

### このモデルの限界

姿勢の変化・選手の回転運動・スキー板と身体の相互作用は扱いません. 空力的な振る舞いはすべて有効面積 A_L, A_D に押し込めています. 文献値を取り込むときは, 有効面積として与えられている値を使います(Cl・Cd だけが示されている文献は, その基準面積 S が分からないと有効面積に換算できません).

### 既知の挙動: 風の効果の向き(要検証)

有効面積が一定のこのモデルでは, **地面に対する踏切速度を同じにして風だけを変えると, 向かい風の方が飛距離が短くなる**という結果になりました(プレースホルダの有効面積での確認. 揚抗比 A_L/A_D = 0.6〜1.4 の範囲で, 約 −8m). 風の符号の実装自体は, 相対速度が同じなら加速度が一致することをテストで確認しています.

| 条件(プレースホルダの有効面積) | 向かい風 (−3 m/s) | 追い風 (+3 m/s) | 差 |
|---|---:|---:|---:|
| 抗力のみ (A_L=0, A_D=0.40 m²) | 83.5 m | 93.3 m | −9.8 m |
| 揚力+抗力 (A_L=0.56 m², A_D=0.40 m²) | 170.2 m | 178.6 m | −8.3 m |

抗力のみなら向かい風が不利になるのは自明で, 揚力を加えても, この代表値の範囲では抗力の効果が上回りました. 一方, 実際の競技では向かい風が有利とされ, FISの風補正点もその前提で設計されています. したがって, **実際のCFD由来の有効面積(迎角や時間に依存する値)を入れたときに, 風の効果の向きを再現できるか**は, シミュレータの妥当性を確かめる重要な検証項目です(ロードマップ v0.4). 再現できない場合は, 有効面積を一定とする仮定や質点近似の限界を示す結果として, そのまま報告します.

なお, 揚抗比 A_L/A_D を 2.0 以上にすると(A_D = 0.40 m² の場合)着地しない(`landed=False`)条件が現れますが, これは揚力が過大な非現実的な領域です.

## ロードマップ

- [x] **v0.1**: 物理コア(`physics.py`)・ヒル形状(`hill.py`)・有効面積モデルのインターフェース(`effective_areas.py`)を実装. 解析解(真空中の放物運動・エネルギー保存・終端速度)との一致をテストで確認
- [ ] **v0.2**: CFD結果の取り込み. 手元の定常ケースの空力値(有効揚力面積・有効抗力面積)の表を読み込む. 非定常CFD(3ケース, 流速26 m/s・スキー板込みの選手・踏切後0.5秒程度)は実行後に追加. 0.5秒より後の値は文献値で置き換える(CFD区間との境目はなめらかにつなぐ)
- [ ] **v0.3**: データ生成. Sobol列/LHSによるサンプリング, 疑似選手ごとの潜在差とジャンプごとのノイズ, 有効面積の摂動(CFD・補間の不確かさ)を入力に加える
- [ ] **v0.4**: 妥当性検証. SkiTBの`JP_data.csv`にある実際の飛距離・ヒル規模との分布比較, 風の効果の向きの検証
- [ ] **v0.5**: 機械学習. ridge → 勾配ブースティング → 小さなMLP. 疑似選手・ヒル単位のGroupKFold, 外挿テスト, 分位点回帰による不確実性
- [ ] **v0.6**: 感度分析. Sobol指数とSHAPの比較

## セットアップ

[uv](https://docs.astral.sh/uv/) を使います.

```bash
uv sync
uv run pytest -q
uv run scripts/demo_flight.py
```

## リポジトリ構成

```
ski-jump-aero-surrogate/
├── pyproject.toml
├── src/
│   ├── hill.py            # ヒル(着地斜面)の形状と, 斜面沿いの飛距離
│   ├── effective_areas.py # 有効揚力面積・有効抗力面積のモデル(一定値, 時間の表)
│   └── physics.py         # 運動方程式と軌道シミュレーション
├── scripts/
│   └── demo_flight.py     # 1回の飛行を実行するデモ
└── tests/
    ├── test_hill_and_effective_areas.py
    └── test_physics.py
```

`src/`は`src`自体を1つのパッケージとして扱います(`from src.physics import simulate`).

## CFDデータの扱い

卒業研究のCFD結果(空力値の表など)は, 研究室(指導教員)の許可を得るまで公開しない方針です. `data/cfd/`は`.gitignore`で除外しており, コードは空力値の表をファイルから読み込む設計にします. テストはダミーの空力値の表で回します.
